2. DETALHAMENTO DAS ENTIDADES E ATRIBUTOS

================================================================================



[ENTIDADE: OWNERS (Proprietários)]

- ID (PK): int(11), Auto Increment, Not Null

- full_name: varchar(100)

- age: int(11)



[ENTIDADE: SPECIES (Espécies)]

- ID (PK): int(11), Auto Increment, Not Null

- name: varchar(100)



[ENTIDADE: VETS (Veterinários)]

- ID (PK): int(11), Auto Increment, Not Null

- name: varchar(300)

- age: int(11)



[ENTIDADE: ANIMALS (Animais)]

- ID (PK): int(11), Auto Increment, Not Null

- name: varchar(100)

- escape_attempts: int(11)

- neutered: bit(1)

- weight_kg: decimal(10,0)

- species_id (FK): int(11) -> Referencia SPECIES(ID)

- owner_id (FK): int(11) -> Referencia OWNERS(ID)



[ENTIDADE ASSOCIATIVA: SPECIALIZATIONS (Especializações)]

*Resolve o relacionamento N:N entre VETS e SPECIES*

- vets_id (FK): int(11), Not Null -> Referencia VETS(ID)

- species_id (FK): int(11), Not Null -> Referencia SPECIES(ID)



[ENTIDADE ASSOCIATIVA: VISITS (Visitas/Consultas)]

*Resolve o relacionamento N:N entre VETS e ANIMALS*

- vets_id (FK): int(11), Not Null -> Referencia VETS(ID)

- animals_id (FK): int(11), Not Null -> Referencia ANIMALS(ID)





================================================================================

3. RESUMO DOS RELACIONAMENTOS E CARDINALIDADES

================================================================================



1. OWNERS (1) ----< (N) ANIMALS

   - Um proprietário pode ter vários animais.

   - Um animal pertence a um proprietário (opcional/NULL permitido no SQL).



2. SPECIES (1) ----< (N) ANIMALS

   - Uma espécie pode classificar vários animais.

   - Um animal pertence a uma espécie (opcional/NULL permitido no SQL).



3. VETS (N) >----< (N) SPECIES  [via tabela SPECIALIZATIONS]

   - Um veterinário pode ser especializado em várias espécies.

   - Uma espécie pode ter vários veterinários especialistas.



4. VETS (N) >----< (N) ANIMALS  [via tabela VISITS]

   - Um veterinário pode atender vários animais.

   - Um animal pode ser atendido por vários veterinários.
