1. Qual comando SQL mostra a quantidade total de exames realizados em cada consulta, identificado pelo ID da consulta?
a. SELECT consultas.id, COUNT(consultas_exames.exame_id) AS total_exames 
FROM consultas 
JOIN consultas_exames ON consultas.id=consultas_exames.consulta_id 
GROUP BY consultas.id;



2. Qual comando SQL mostra a quantidade total de consultas realizadas por cada médico, identificado pelo nome?
a.
SELECT medicos.nome, COUNT(consultas.id) AS total_consultas 
FROM medicos 
JOIN consultas ON medicos.id=consultas.medico_id 
GROUP BY medicos.nome;

7. Como listar todos os pacientes que não possuem consultas registradas?

9. Como criar um TRIGGER que atualiza a coluna 'ultima_consulta' da tabela pacientes toda vez que uma nova consulta for realizada?
c. CREATE TRIGGER atualiza_ultima_consulta 
AFTER INSERT ON consultas FOR EACH ROW UPDATE pacientes SET ultima_consulta=NEW.data_consulta WHERE id=NEW.paciente_id;

Qual comando SQL cria um TRIGGER que impede a exclusão de um médico se ele tiver consultas agendadas?
d. CREATE TRIGGER impede_exclusao_medico 
BEFORE DELETE ON medicos FOR EACH ROW BEGIN IF (SELECT COUNT() 
FROM consultas WHERE medico_id=OLD.id) > 0 THEN SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT='Não é possível excluir um médico com consultas agendadas'; END IF; END;
