01. Como inserir um registro na tabela 'visits' associando um animal e um veterinário pelos seus respectivos IDs?
a. INSERT INTO visits (vets_id, animals_id) 
VALUES (1, 1);



02. Qual é a consulta correta para selecionar todos os animais com peso entre 10 e 20 kg, incluindo os limites, na tabela 'animals'?
c. SELECT * 
FROM animals 
WHERE weight BETWEEN 10 AND 20;



03. Qual consulta retorna os nomes dos animais e suas espécies correspondentes, usando a tabela 'animals' e a tabela 'species', com um LEFT JOIN baseado na coluna 'species_id'?
d. SELECT animals.name AS animal_name, species.name AS species_name 
FROM animals 
LEFT JOIN species ON animals.species_id=species.ID;



4.Como selecionar todos os campos da tabela 'animals', mas apenas exibir o resultado em ordem alfabética decrescente baseado no nome do animal?
a. SELECT * 
FROM animals 
ORDER BY name DESC;



5. Qual consulta retorna a quantidade total de animais por espécie, em ordem decrescente, com base na quantidade de animais de cada espécie?
a. SELECT species.name, COUNT(animals.ID) as total_animals 
FROM animals JOIN species ON animals.species_id=species.ID 
GROUP BY species.name 
ORDER BY total_animals DESC;



6. Como obter a média do peso dos animais de uma determinada espécie com ID 1 na tabela 'animals'?
c. SELECT AVG(weight_kg) 
FROM animals 
WHERE species_id = 1



7. Para inserir um novo registro na tabela 'animals' com ID, nome, escape_attempts, neutered, weight_kg, species_id e owner_id, qual a sintaxe correta?
a. INSERT INTO animals (ID, name, escape_attempts, neutered, weight_kg, species_id, owner_id)

8. Como atualizar o número de tentativas de fuga para 5 para todos os animais chamados 'Felix' na tabela 'animals'?
d. UPDATE animals SET escape_attempts = 5 
WHERE name = 'Felix'



9. Como selecionar todos os donos de animais na tabela 'owners', ordenados por idade decrescente?
d. SELECT * FROM owners ORDER BY age DESC;



10. Qual a sintaxe correta para selecionar todos os campos da tabela 'animals'?
